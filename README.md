# NeuroForge

NeuroForge is the home of **Final SRM** (Sparse Recruitment Machine, final revision), an AI architecture in which intelligence comes from reusable machinery rather than from parameter count alone. That machinery is:
- factored concepts;
- structural matching;
- composition of domain-general primitives into temporary circuits;
- typed predictions that become knowledge only when evidence promotes them;
- a real UNKNOWN state;
- local continual learning;
- an explicit compute economy.

The model is packaged as versioned components that can be retrained individually.

**Status:** architecture plan v1.0 approved; implementation not started.
